# Bundled UI fonts

Be Vietnam Pro: @fontsource/be-vietnam-pro@5.3.0 (SIL OFL-1.1).
IBM Plex Mono: @fontsource/ibm-plex-mono@5.3.0 (SIL OFL-1.1).

Unmodified normal WOFF2 latin + Vietnamese subsets from registry.npmjs.org; licenses beside files. Vite library mode inlines them into the shipped JS. Document-scoped FontFace registration works across Streamlit v2 ShadowRoot, local/offline staging and UAT. No package/runtime dependency added. Legal/DOCX/XLSX fonts unchanged.
